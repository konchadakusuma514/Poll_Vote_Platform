# 🗳️ PollPulse — Real-Time Polling & Voting Platform

A modern, full-stack Polling & Voting platform built with **Python (Flask), SQLite, React, Tailwind CSS, Recharts, and Lucide Icons**.

---

## 🚀 How to Run with Python

In your terminal inside the project directory:

```bash
python app.py
```
*(or `py app.py`)*

You will see:
```text
====================================================================
  🗳️  POLLPULSE — REAL-TIME POLLING & VOTING PLATFORM
  ✨  Status: Server is ACTIVE & Ready!
  🌐  Multi-Language: English | Hindi | Telugu | Tamil | Spanish
  🌗  Theme: Light Mode (Default) & Dark Mode
  🛡️  Zero Duplicate Voting Guarantee
====================================================================
  👉  COPY & PASTE THIS URL INTO YOUR CHROME / BROWSER:
      http://127.0.0.1:5000
====================================================================
```

> 🔒 Chrome will **not** open automatically. Simply copy `http://127.0.0.1:5000` and paste it into any browser tab!

## ✨ Features

- 🎨 **Professional SaaS Design**: Clean Plus Jakarta Sans typography, ambient background mesh glows, soft borders, and electric indigo gradients.
- 🌗 **Light & Dark Mode**: Modern crisp **Light Mode by default**, with an instant 🌙/☀️ toggle.
- 🌐 **Multi-Language Support**: English (Default), Hindi (हिंदी), Telugu (తెలుగు), Tamil (தமிழ்), and Spanish (Español).
- 🤖 **AI Poll Idea Generator**: Instant viral question and option templates with 1 click.
- 📺 **Live Projector / Presenter Mode**: Full-screen presentation view with giant QR code for classroom and stage voting.
- 🔊 **Audio & Confetti Effects**: Celebratory chime and confetti when voting.
- ⚡ **Live Activity Ticker**: Real-time ticker showing recent votes on the homepage.
- 👑 **Top Creators Leaderboard**: Community ranking of top poll creators.
- 🛡️ **Zero Duplicate Voting**: Strict database constraints ensuring only one vote per user per poll.
- 💬 **Discussions & Comments**: Users can comment on polls and upvote/like insightful arguments.
- 🔥 **Emoji Reactions**: Express sentiment with 🔥, 💡, 🚀, 👏, and 🤔.
- 📊 **Visual Charts**: Interactive Bar Charts and Donut Charts powered by Recharts.
- 📥 **Data Export**: Export vote counts and percentages to CSV or JSON with one click.
- 🔗 **QR Code Sharing**: Dynamic scanable QR code generator for instant mobile voting.
